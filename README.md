# Folio

A light, fast, cross-platform Markdown viewer and editor for Windows, macOS and Linux, built with [Tauri](https://tauri.app).

## Planned features (v1)

- Read / Split / Edit modes with synced scrolling
- Tabs, with the option to move a tab to a new window
- Live reload when the file changes on disk
- GitHub-flavored Markdown: tables, task lists, footnotes, syntax-highlighted code
- Clickable task checkboxes that update the source file
- Click-to-jump between preview and source
- Mermaid diagrams and KaTeX math (loaded on demand)
- Table of contents sidebar, find, light/dark themes, recent files
- "Open with" file association
